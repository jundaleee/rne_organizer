## 3. 핵심 방법론: DDI 지표

**정의**: `DDI (DNA Degradation Index) = Ct(600bp) − Ct(100bp)` — qPCR 기반 신규 지표. 본 연구 참신성의 핵심.

**원리**: 열을 받으면 긴 DNA 조각이 짧은 조각보다 먼저 끊어진다. 같은 유전자 부위에서 짧은 구간(100bp)과
긴 구간(600bp)을 각각 qPCR로 증폭해, DNA가 온전하면 두 Ct값이 비슷하고 심하게 부서졌으면 Ct(600bp)만
크게 상승하는 것으로 붕괴 정도를 단일 숫자로 정량화한다.

**화학적 근거**
- G-C 결합: 수소결합 3개 (결합 에너지 ~15.0 kcal/mol)
- A-T 결합: 수소결합 2개 (~10.6 kcal/mol)
- 고온에서 A-T 부위가 먼저 절단 → 잔존 조각의 GC 함량 상승
- 아레니우스 방정식(`k=Ae^(-Ea/RT)`, Ea≈130 kJ/mol)으로 온도별 절단 속도 모델링
- 산성 조건: 탈퓨린화(퓨린 염기의 N-글리코시드 결합 가수분해)로 별개 경로 붕괴

**목표 이중화**
1. 1차 (분류): 75°C 이상 처리 여부 (살모넬라 사멸 기준 = 75°C 15초)
2. 2차 (회귀): 정확한 온도·시간 예측

분류를 1차 목표로 두는 이유: 데이터가 적어도 명확한 성과가 나오는 안전장치. 회귀가 안 되어도 연구는 성공.

## 4. 연구 동기의 재정립

**폐기된 프레임**: 초기 "살모넬라 검출" 프레임. 살모넬라 유무는 특이 유전자(invA 등) 직접 검사가
이미 더 직접적이고 확실하며, 열처리 부족과 균 존재를 확정적으로 연결할 수 없다(조리 후 재오염 가능성).

**최종 프레임**: "제조사 공정 기록(HACCP)의 제3자 사후 검증 불가능성"

핵심 논리: 기존 온도 검증 기술(HPT/HDT, 열전대, HACCP 로그)은 전부 (a) 가공 중에 (b) 제조사 자신이
(c) 특수 장비를 제품에 직접 삽입해서 측정한다. 완제품만으로 실제 가공 이력을 독립적·사후적으로
검증하는 기술은 부재한다 (웹검색으로 gap 실재 확인 완료).

비유: 요리사가 조리 중 온도계로 재는 기술 = 있음(HACCP). 다 식은 요리를 받아서 몇 도로 조리됐는지
역추적 = 없음(본 연구). 답하는 질문은 "균이 있냐"가 아니라 "공정 기록이 진짜냐".

**스코프 제한(중요)**: 본 연구는 100°C 이하 가열조리에 한정한다. 121°C 이상 상업적 멸균(레토르트,
통조림)은 DNA가 완전 분해되어 신호 포화(100bp도 미검출)되므로 DDI로 구분 불가하다. 계획서에 명시할 것.

## 7. 프라이머 설계 전 과정 (실습 기록)

**서열 확보**: NCBI RefSeq `NC_001323.1` (*Gallus gallus* mitochondrion, complete genome).
전체 게놈 16,775 bp. COI(COX1) 영역: 6645~8192번째, 1548 bp. GC 함량 47.2%.
COI가 GTG로 시작(조류 COX1의 정상적 시작코돈 패턴).

**설계 도구 흐름**: NCBI에서 `sequence.fasta` 다운로드(전체 게놈) → COI 영역만 추출
(`COI_only.fasta`, 1548bp) → Primer3(primer3.ut.ee): COI 서열 입력, Product Size 95-105 →
580-620, Primer Size 18/20/22, Tm 58/60/62, GC 40/60 → Primer-BLAST 특이성 검증
(Database: Nucleotide collection nr/nt — RefSeq mRNA로 하면 미토콘드리아 누락됨,
Organism: *Gallus gallus* taxid:9031, Enable specificity check 반드시 체크).

**최종 확정 프라이머**

| 구분 | 방향 | 서열 (5'→3') | 위치 | Tm | GC% |
|---|---|---|---|---|---|
| 100bp | Forward (COI-100F) | ACTCCTCTCCTTACCCGTCC | 585 | 60.03 | 60% |
| 100bp | Reverse (COI-R) | GGATTGGGTCTCCTCCTCCA | 688 | 60.33 | 60% |
| 586bp | Forward (COI-586F) | AGCCTTCTAATTCGCGCAGA | 103 | 59.82 | 50% |
| 586bp | Reverse (공용) | GGATTGGGTCTCCTCCTCCA | 688 | 60.33 | 60% |

핵심 설계: 두 앰플리콘이 같은 끝점(688)을 공유 → 586bp가 100bp를 완전히 포함하는 구조.
"긴 조각이 살아있으면 그 안의 짧은 조각도 당연히 살아있다"는 DDI 논리가 명확해진다.

**특이성 검증 결과**: 전 세계 300여 개 닭 품종·개체 미토콘드리아 서열에서 완벽 일치. Forward
11번째 C 미스매치는 정상적 종내 다양성(프라이머 중앙부라 결합 영향 적음). 핵 염색체 NUMT 히트
있으나 미토콘드리아 카피수가 압도적이라 무시 가능.

**주문 규격**: 3종(COI-100F, COI-586F, COI-R 공용), 0.2 μmole, Desalting 정제, 5'/3' 변형 없음,
동결건조. 업체: 바이오니아/마크로젠/코스모진텍. 예상 45,000~75,000원, 배송 1~2주.

## 8. 실험 설계 (4주 프로토콜)

**시료 구성 (총 162개)**
- 열처리군 (126개): 온도 7수준(50,60,70,75,80,90,100°C) × 시간 3수준(15,30,60분) × 반복
- 양념 교란군 (27개): 무양념/간장/고추장 × 온도[60,80,100] × 30분 × 반복3
- 대조군·검증군 (9개): 생닭 3 + 시중 가공식품 6

> ⚠️ 원문 그대로 옮긴 숫자다. 7수준×3수준×반복3 = 63개로 계산되어 "126개"와 맞지 않는다
> (반복 횟수가 6이면 126이 맞는다). 실험 계획 확정 전에 **반복 횟수를 3인지 6인지 먼저
> 확인**할 것 — DNA 추출/qPCR 병목 계산(아래)에 직접 영향을 준다.

75°C를 반드시 포함 — 분류 문제의 결정 경계.

**병목 분석**: 수비드 열처리는 병목 아님(방치형). DNA 추출이 최대 병목(1인 하루 20~24개, 3명이면
60개/일). qPCR이 2차 병목(96웰 = 시료당 4웰 → 1회당 20~24개, 주2회×4주 = 160~190개).
→ 실현 가능 시료 수 150~180개.

**4주 스케줄**
1. 1주차: 열처리 집중 (수비드 3대 병렬, 시간차 회수로 1대=1온도=9시료/일)
2. 2~3주차: DNA 추출 + qPCR 병렬 (추출 다 끝내고 qPCR 시작하면 시간 부족)
3. 4주차: 검증군 + 재실험 + 데이터 정리 → CSV 변환

**학교 보유 장비(2024 첨단기자재 현황 확인)**: Real-Time PCR AB StepOnePlus(생명과학실험2실),
Thermal Cycler Bio-rad T100, Gel Doc XR+, NanoDrop 2000, 고속원심분리기 LABOGENE 2236R(기자재실).

**개학 전 필수 확인(팀원 C)**: 마이크로 원심분리기(13,000rpm+, 1.5mL 튜브용) — 2236R은 대용량
로터라 스핀컬럼에 부적합, 없으면 실험 불가(즉시 구매 15~30만원). 56°C 유지 장비(없으면 수비드로
대용). StepOnePlus 플레이트 규격(0.1mL vs 0.2mL). 방과 후 사용 가능 시간.

→ 실제 측정 행위는 NanoDrop 1회 + qPCR 1회, 총 2번뿐.

## 9. 세특·발표·문서 산출물

## 11. 노이즈 강건 ML 파이프라인

양념은 단순 노이즈가 아니라 DNA에 **두 가지 완전히 다른 경로**로 영향을 준다.

| 경로 | 영향 대상 | 메커니즘 | 양념 |
|---|---|---|---|
| 매트릭스 간섭 | DNA_conc, purity | 추출 방해·흡광도 오염 | 간장, 고추장 |
| 화학적 분해 | DDI 자체 | 산성 탈퓨린화 | 고추장(pH 4.5~5)만 |

"온도가 높아서 DDI 높다"와 "고추장이라서 DDI 높다"를 구분 못 하면 완전히 틀린 온도 예측이 된다.

**노이즈 강건 데이터(`ddi_data_v2.csv`, 84개)** 채널 분리 설계: 열 손상 채널(아레니우스로 Ct_600
증가), 산성 손상 채널(gochujang만, (7-pH)에 비례해 Ct_600에 독립적으로 추가), 매트릭스 간섭
채널(marinade별 conc 감소·purity_230 저하, DDI에는 영향 안 줌), 측정 노이즈(Ct 표준편차 0.2~0.4),
배치 효과(추출 날짜별 ±5% 계통 오차), 실패 모드(5% undetermined, 3% outlier_suspect → qc_flag).
구성: 열처리군 63 + 양념군 18(soy/gochujang) + 대조군 3.

**사전등록 검증 기준표(결과 보기 전 확정)**

| 항목 | 통과 기준 | 실패 시 대응 |
|---|---|---|
| Nested CV MAE (온도) | <10°C | 하이퍼파라미터 재탐색 |
| Marinade 성능 격차 | 무양념 vs 양념 <5°C | marinade 명시 재투입 |
| Feature Ablation purity | marinade 무관 일정 기여 | 채널 구분 변수 추가 |
| Blind Test (75°C 분류) | ≥85% | 결정경계 데이터 보강 |
| Synthetic-to-Real Gap | 실측 20%p+ 하락 시 재보정 | 파라미터 역산 |
| 고추장 DDI 분리 | SHAP으로 열/산 분리 가능 | pH 별도 투입 |

사전등록 = 결과 보고 기준 끼워맞추기(p-hacking) 방지.

**실행 결과**: none 그룹(n=60)에서 XGBoost가 검량선보다 유의미하게 우수
(p<0.0001, MAE 6.1 vs 10.9) — **⚠️ 시뮬레이션(합성 데이터) 결과이며 실측 검증 전이다.**

## 12. 가설 3회 반전의 전체 기록

질문: "모델이 산 채널을 쓰는가?"

1. **1차(계정4 감사) — 가설 A**: pH 제거해도 MAE 거의 불변(10.5757→10.5750) → "산 채널을 거의
   안 쓴다". (부수 발견: 블라인드 테스트 데이터 누출 — 학습에 쓰인 샘플을 그대로 재사용)
2. **2차(Gemini 반증) — 가설 B**: 다중공선성(pH↔DDI) 의심, n=5 부트스트랩 오용 지적,
   0.0007°C 차이 과잉해석 비판(일부 맞고 일부 과장).
3. **3차(다중공선성 검증) — 가설 B 기각, 가설 C 등장**: pH↔DDI 상관은 Simpson's paradox(그룹
   내부는 약함) → Gemini 가설 기각. 대신 pH↔marinade 카테고리 R²=0.96 발견 → 진짜 중복은
   pH-DDI가 아니라 pH-카테고리.
4. **4차(pH-only 2×2 재실험) — 가설 역전, 최종 결론**: 원핫 유/무 × pH 유/무 4조합 중
   원핫은 무의미(A=B), pH 제거 시 성능 뚜렷이 악화(C/D) → "pH가 실제로 유의미하다"로 역전.

**최종 해석**: 모델은 산 정보를 안 쓰는 게 아니라, marinade 카테고리를 통해 이미 그 정보를 갖고
있어서 pH라는 별도 변수가(원핫과 함께 있을 땐) 불필요했다. 카테고리를 빼면 pH가 그 역할을
유의미하게 수행한다. "산 화학 이해 못 함"과 "정보를 효율적으로 씀"은 완전히 다른 이야기다.

## 13. 재현성 위기와 근본 원인 규명

동일 조건 baseline인데 값이 불일치했다: `feature_ablation.md`(원본) 10.5757, `multicollinearity_check.md`
10.5757(일치), `ph_only_test.md` 10.7214(불일치). requirements.txt 4계정 전부 대조했지만 완전 동일
(xgboost 3.3.0, pandas 3.0.3, numpy 2.4.4, scikit-learn 1.9.0, scipy 1.18.0) → "버전 차이" 가설 기각.

**진짜 원인 2가지**
1. **numpy NaN 비교 함정**: `numpy.array_equal()` 기본값은 `NaN != NaN`. marinade="none" 60개 행에서
   marinade_pH가 NaN이었는데, `equal_nan=True`로 비교하니 X, y 배열이 완전 일치했다 → 데이터·전처리
   로직은 애초에 동일했음.
2. **원본 스크립트 미보관**: `ph_only_test.md`는 "재현"이 아니라 "설명만 보고 독립적으로 다시 짠
   코드"였다. 원본 `.py`가 저장 안 됐으니 "같은 걸 했다"는 설명만으로 진짜 재현을 보장할 수 없다.

**규칙화**: 지금부터 모든 분석 `.py`는 실행 즉시 git commit한다.

**결론**: A/B/C/D 내부 상대비교는 유효 확정(그 세션 내에서 내적 일관). 절대 수치의 교차 세션
비교만 무효.
