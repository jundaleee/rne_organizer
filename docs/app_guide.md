# 총괄 앱 사용 가이드 (실험 담당 팀원용)

코드나 git을 몰라도 된다. **링크 하나만 열면 된다.**

## 접속 방법

1. 노트북에서 브라우저(크롬 등)로 앱 링크에 접속한다. (링크는 팀 단톡방에 고정)
2. 로그인 없이 바로 화면이 뜬다. 왼쪽 사이드바에서 원하는 화면을 클릭한다.

| 사이드바 메뉴 | 용도 |
|---|---|
| 🏠 진행현황 | 목표 162개 중 지금까지 몇 개 모였는지, 그룹별(열처리/양념/대조군) 진행률 |
| 🧪 데이터 입력 | 오늘 측정한 NanoDrop·qPCR 수치를 입력하는 곳 |
| 🔮 예측(Dry-Lab) | 값 6개를 넣으면 예상 가공 온도를 알려주는 곳 |
| 📄 문서 | 연구계획서, 실험 가이드 등 파일 모음 |
| 👥 팀 활동 | 누가 언제 몇 개 입력했는지 |
| ⚙️ 설정 | Claude API 키, GitHub 백업 토큰 입력 (최준혁만 건드리면 됨) |

## 처음 배포했을 때 한 번만 (최준혁)

앱이 막 배포되면 AI 감사관이 꺼진 채로 시작한다. `⚙️ 설정` 화면을 열고:

1. **Claude API 키**란에 console.anthropic.com에서 받은 키를 붙여넣고 저장
2. (선택) **GitHub 자동 백업**란에 저장소(`jundaleee/rne_organizer`)와
   github.com/settings/tokens에서 발급한 토큰을 넣고 저장
   — 이건 앱이 재배포돼도 입력한 데이터가 안 사라지게 하는 안전장치다. 안 해도 앱은 잘 동작한다.

여기서 저장한 값은 팀원 전체가 공유해서 쓴다. **딱 한 번만** 하면 되고, 이후 팀원들은
이 화면을 볼 필요가 없다.

> ⚠️ 이 앱엔 로그인이 없다. 링크를 아는 사람이면 누구나 `⚙️ 설정`에서 값을 바꿀 수
> 있으니, 링크는 팀 단톡방 밖으로 퍼지지 않게 한다.

## 데이터 입력하는 법 (실험 담당이 가장 자주 쓰는 화면)

1. `🧪 데이터 입력` 클릭
2. 시료 ID, 담당자, 그룹(열처리군/양념교란군/대조군), 온도·시간, 양념 종류를 고른다
3. NanoDrop 값(DNA 농도, A260/280, A260/230)과 qPCR 값(Ct_100, Ct_600)을 입력한다
4. **제출**을 누르면:
   - DDI가 자동 계산된다 (Ct_600 − Ct_100이라 직접 계산 안 해도 됨)
   - "AI 감사관"이 입력값이 이상해 보이는지 바로 알려준다 (예: A260/230이 너무 낮으면
     세척 부족 의심 → 재세척 권장)
   - 값이 `data/processed/samples_log.csv`에 자동으로 쌓인다

값을 잘못 입력했다면 **그 행을 고치지 말고**, 같은 시료 ID로 새로 입력하면서 메모란에
"정정: OO 오타"라고 남긴다. (이유: `docs/raw/README.md` 참고 — 값을 덮어쓰면 나중에
어떤 게 진짜 측정값이었는지 알 수 없어진다.)

## qPCR에서 Undetermined(미검출)가 떴을 때

고온 처리군(90°C, 100°C)에서는 600bp가 아예 검출 안 될 수 있다. 이건 정상적인 현상이다.
입력창에서 Ct_600을 비워두거나 "Undetermined" 체크박스를 켜면 앱이 자동으로 Ct=40으로
처리하고, 같은 그룹에서 미검출이 너무 많이 쌓이면(데이터 포화 위험) AI 감사관이
"예비 프라이머(200bp/400bp) 카드를 가동할 시점"이라고 알려준다.

## 예측 화면은 언제 쓰나

아직 실측 데이터가 다 안 모였어도, 시뮬레이션(가상) 데이터로 학습한 모델로 미리 테스트해볼
수 있다. 단, 이 화면 위에 뜨는 **"⚠️ 이 모델은 시뮬레이션(합성) 데이터로 학습되었습니다"**
배너가 보이는 동안은 예측값이 실제 연구 결과가 아니라는 뜻이다. 9월 실측 데이터가 다 들어가서
`scripts/build_final_model.py`가 실측 데이터로 다시 학습되면 배너가 사라진다.

## 문제가 생기면

앱이 안 열리거나 이상하게 동작하면 화면 캡처해서 최준혁에게 보낸다. 코드를 몰라도 되니
직접 고치려 하지 않아도 된다.
